---
title: 'Auth Rate Limiting'
---

Modelence includes built-in rate limiting on all authentication endpoints to protect against brute force attacks and abuse.

## Default Rate Limits

- **Signup**: 20 attempts per 15 minutes, 200 per day (per IP)
- **Login**: 50 attempts per 15 minutes, 500 per day (per IP)
- **Email Verification** (resend): 10 per 15 minutes, 100 per day (per IP); 1 per 60 seconds, 10 per day (per user)
- **Password Reset**: 10 per 15 minutes, 100 per day (per IP); 5 per hour, 10 per day (per email)
- **Magic Link**: 10 per 15 minutes, 100 per day (per IP); 5 per hour, 10 per day (per email)
- **One-Time Code**: 20 per 15 minutes, 100 per day (per IP); 10 per hour, 20 per day (per email)
- **Anonymous Session Creation**: 100 per 15 minutes, 1,000 per day (per IP)

These limits are automatically enforced and will throw a [RateLimitError](/api-reference/modelence/index/classes/RateLimitError) when exceeded.

The session-creation limit applies only when an HTTP request or WebSocket handshake needs a new anonymous session because its token is missing or unknown. Reusing an existing session does not consume this quota. HTTP requests receive 429 when the limit is exceeded, and WebSocket connections are rejected. Server-side session creation without a client IP and authenticated session rotation retain their existing behavior.

Adjust the limits for traffic behind shared IPs using `auth.rateLimits.sessionCreation`. Overrides merge by window, so changing the 15-minute limit preserves the daily limit:

```typescript
import { startApp } from 'modelence/server';
import { time } from 'modelence';

startApp({
  auth: {
    rateLimits: {
      sessionCreation: [{ type: 'ip', window: time.minutes(15), limit: 200 }],
    },
  },
});
```

HTTP requests and the built-in Socket.IO provider use the same `security.trustedProxies`, `MODELENCE_TRUSTED_PROXIES`, and `security.clientIpHeader` configuration to identify clients behind a proxy.

## Handling Rate Limit Errors

```typescript
import { loginWithPassword } from 'modelence/client';
import { RateLimitError } from 'modelence';

async function handleLogin(email: string, password: string) {
  try {
    await loginWithPassword({ email, password });
  } catch (error) {
    if (error instanceof RateLimitError) {
      console.error('Too many attempts. Please try again later.');
    } else {
      console.error('Login failed:', error.message);
    }
  }
}
```

## Disposable Email Detection

Aside from rate limiting, Modelence also includes automatic protection against 100k+ disposable email services,
and keeps a periodically updated dataset of all disposable email providers.
