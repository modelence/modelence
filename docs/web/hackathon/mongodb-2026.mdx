database and hosting out of the box, so you can spend the day on your
project instead of on infrastructure. This page has everything you need to get
something live before demos and earn credits for it.

## Start building

Build with your own coding agent, whether that's Claude Code, Cursor, or Codex.

### Starting a new project

Ask your coding agent to create the app and connect it to Modelence Cloud, which provisions a MongoDB
database for your local environment:

```text
Use https://modelence.com/skill.md to create a new Modelence app and connect it to a local environment
```

When you're ready to ship, ask it to deploy:

```text
Use https://modelence.com/skill.md to deploy this project
```

### Bringing an existing app

If your team already has an app, you can still host it on
Modelence Cloud and get a provisioned MongoDB Atlas database injected as `MONGODB_URI`. Point your coding
agent at the deploy guide:

```text
Use https://modelence.com/skill.md to deploy to Modelence
```
