## Start building

Build with your own coding agent, whether that's Claude Code, Cursor, or Codex.

### Starting a new project

Create a project and connect it to Modelence Cloud, which provisions a MongoDB database for your local
environment:

```bash
npx create-modelence-app@latest my-app
cd my-app
npx modelence@latest setup
npm run dev
```

When you're ready to ship, deploy from the project directory:

```bash
npx modelence@latest deploy
```

### Bringing an existing app

If your team already has an app, you can still host it on
Modelence Cloud and get a provisioned MongoDB Atlas database injected as `MONGODB_URI`. Point your coding
agent at the deploy guide:

```text
Use https://docs.modelence.com/deploy/setup.md to set up Modelence deployment for this project
```
