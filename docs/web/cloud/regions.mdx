Modelence Cloud runs on AWS. Each production environment runs in one region, which you pick when you
deploy the environment for the first time. The app's containers, its MongoDB Atlas database and its
managed resources are all created in that region.

## Available regions

| Region | AWS region | Status |
| --- | --- | --- |
| US West (Oregon) | `us-west-2` | Available |
| Canada (Central) | `ca-central-1` | Available |
| Europe (Frankfurt) | `eu-central-1` | Available |
| US East (N. Virginia) | `us-east-1` | On request |
| US East (Ohio) | `us-east-2` | On request |
| US West (N. California) | `us-west-1` | On request |
| South America (São Paulo) | `sa-east-1` | On request |
| Europe (Ireland) | `eu-west-1` | On request |
| Europe (London) | `eu-west-2` | On request |
| Europe (Paris) | `eu-west-3` | On request |
| Europe (Stockholm) | `eu-north-1` | On request |
| Asia Pacific (Mumbai) | `ap-south-1` | On request |
| Asia Pacific (Tokyo) | `ap-northeast-1` | On request |
| Asia Pacific (Seoul) | `ap-northeast-2` | On request |
| Asia Pacific (Osaka) | `ap-northeast-3` | On request |
| Asia Pacific (Singapore) | `ap-southeast-1` | On request |
| Asia Pacific (Sydney) | `ap-southeast-2` | On request |

Regions marked **Available** can be picked by any organization. To deploy to a region marked **On
request**, email [support@modelence.com](mailto:support@modelence.com) with the region you need, and
we'll enable it for your organization.

Sandbox environments always run in US West (Oregon).
